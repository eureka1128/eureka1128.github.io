記事に目次を導入する#

記事に ShowToc = true を追記。例 ↓

+++
date = '2025-02-22T15:41:51+09:00'
draft = false
title = 'KEK-PH2025の次の日'
ShowToc = true  #ここを追記
+++

 

右上にarchiveを導入する#

content/archives.md を作り、次の内容を書き込む。

---
title: "Archive"
layout: "archives"
url: "/archives/"
summary: archives
---

hugo.tomlに以下の内容を追記。

[[menu.main]]
identifier = "archives"
name = "Archive"
url = "/archives/"
weight = 10

参考:

  • Archives Layout – PaperMod

 

右上にtagを導入する#

content/tags/_index.md を作り、次の内容を書き込む。

---
title: "Tags"
date: 2025-02-25T19:10:49+09:00
draft: false
description: Example description.
---

各記事に tags = ['Tag A', 'Tag B'] を追記。例 ↓

+++
date = '2025-02-22T15:41:51+09:00'
draft = false
title = 'KEK-PH2025の次の日'
tags = ['Tag A', 'Tag B'] #ここを追記
+++

hugo.tomlに以下の内容を追記。

[[menu.main]]
identifier = "tags"
name = "Tags"
url = "/tags/"
weight = 20

参考:

  • Add description to taxonomy “tags” term
  • Taxonomies

 

数式を導入する#

  1. themes/papermod/layouts/partials/math.html を作成
  2. math.htmlに次の内容をコピー
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/katex.min.css" integrity="sha384-zh0CIslj+VczCZtlzBcjt5ppRcsAmDnRem7ESsYwWwg3m/OaJ2l4x7YBZl9Kxxib" crossorigin="anonymous">
<script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/katex.min.js" integrity="sha384-Rma6DA2IPUwhNxmrB/7S3Tno0YY7sFu9WSYMCuulLhIqYSGZ2gKCJWIqhBWqMQfh" crossorigin="anonymous"></script>
<script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.21/dist/contrib/auto-render.min.js" integrity="sha384-hCXGrW6PitJEwbkoStFjeJxv+fSOOQKOPbJxSfM6G5sWZjAyWhXiTIIAmQqnlLlh" crossorigin="anonymous"></script>
<script>
    document.addEventListener("DOMContentLoaded", function() {
        renderMathInElement(document.body, {
          // customised options
          // • auto-render specific keys, e.g.:
          delimiters: [
              {left: '$$', right: '$$', display: true},
              {left: '$', right: '$', display: false},
              {left: '\\(', right: '\\)', display: false},
              {left: '\\[', right: '\\]', display: true}
          ],
          // • rendering keys, e.g.:
          throwOnError : false
        });
    });
</script>
  1. 同じくpartialsフォルダ内にある、extend_head.htmlに次の行を追加
{{- /* Head custom content area start */ -}}
{{- /*     Insert any custom code (web-analytics, resources, etc.) - it will appear in the <head></head> section of every page. */ -}}
{{- /*     Can be overwritten by partial with the same name in the global layouts. */ -}}
{{ partial "math.html" . }}     # ここを追加
{{- /* Head custom content area end */ -}}
  1. contens内のmdファイルに math = true を追記。例↓
+++
date = "2025-02-23T18:42:12+09:00"
draft = false
title = "立ち止まって研究の方針を確認"
math = true  
+++
  1. hugo.tomlに以下のように[params]を追記
baseURL = 'https://eureka1128.github.io/'
languageCode = 'ja-jp'
title = 'ネムリカの記録'
theme = 'PaperMod'

[params]  ##ここの2行を追記
  math = true

おまけ : hugo.tomlの中身#
